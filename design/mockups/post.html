Avalonia 剪贴板和 DataGrid 的问题

记录最近 Avalonia 桌面软件开发解决的两个问题：剪贴板复制崩溃、Tab 切换 DataGrid 卡顿，分析根因并给出解决方案。

剪贴板复制崩溃

在 Windows 上调用 Clipboard.SetTextAsync 偶发崩溃，堆栈指向剪贴板打开失败。排查后发现是 Avalonia 的剪贴板实现与系统剪贴板监听软件冲突：

// 重试 + 延迟释放，规避剪贴板占用冲突
for (int i = 0; i < 3; i++)
{
    try
    {
        await clipboard.SetTextAsync(text);
        break;
    }
    catch (ClipboardException)
    {
        await Task.Delay(50);
    }
}

Tab 切换 DataGrid 卡顿

大量行数据绑定 DataGrid 时，TabControl 切换页签明显掉帧。原因是虚拟化被关闭导致一次性 measure 所有行：

关键结论：保持 VirtualizationMode="Standard"，并避免在 LoadingRow 中做重量级操作。

定位过程

使用 dotTrace 抓取切换页签时的采样，热点集中在 MeasureOverride，确认是行容器全量布局……

figure 1 · performance flame graph

解决方案

通过附加行为在页签失活时冻结布局、切回时恢复，实测万行数据切换耗时从 900ms 降至 40ms。
