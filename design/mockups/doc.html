项目简介

site/doc/getting-started/intro.md

CodeWF 是一个前后端分离的博客与在线工具网站：Web API 负责读取文件型内容仓库并渲染 Markdown，Next.js 前台提供文章、专题、文档、工具与多语言内容，React + Ant Design 后台负责内容维护。

本地运行

安装依赖并启动三个子应用：

npm install
dotnet restore CodeWF.slnx

npm run dev:api        # 后端  http://localhost:5002
npm run dev:frontend   # 前台  http://localhost:5000
npm run dev:admin      # 后台  http://localhost:5001

内容仓库

默认资源仓库路径为 Site:LocalAssetsDir，文章正文存放于 YYYY/MM/slug.md，元数据使用同名 .yml sidecar 文件：

directory tree · Assets.Dotnet9

多语言

多语言资源通过同名后缀文件加载，例如 about.en.md、tools.ja.json。缺少对应语言文件时，回退到默认中文内容。
