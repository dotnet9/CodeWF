# 解决方案总览

CodeWF 现在按开源项目的习惯拆成三层：

```text
src/
  CodeWF.Api/     公开内容 API
  CodeWF.Web/     面向访客的公开站点
docs/            设计与说明文档
```

## 目标

- 让站点内容完全由文件仓库驱动，便于版本管理和本地维护。
- 让前台页面保持服务端可读的 HTML 结构，方便 SEO。
- 让布局、语言和资源浏览符合实际维护场景，而不是演示页式的堆叠卡片。

## 已落地能力

- 文章列表、详情、专题、分类、标签、搜索、RSS、Sitemap。
- 关于、捐赠、隐私、时间线、友链等站点页面。
- Markdown 渲染（标题锚点、目录、代码高亮）与多语言资源回退。

## 后续扩展方向

- 公开站点继续补齐页面体验和 SEO 结构化标签。
- 搜索与内容聚合继续增强。
