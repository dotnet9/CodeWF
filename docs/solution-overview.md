# 解决方案总览

CodeWF 现在按开源项目的习惯拆成三层：

```text
src/
  CodeWF.Api/     内容与管理 API
  CodeWF.Web/     面向访客的公开站点
  CodeWF.Admin/   React 后台
docs/            设计与说明文档
```

## 目标

- 让站点内容完全由文件仓库驱动，便于版本管理和本地维护。
- 让前台页面保持服务端可读的 HTML 结构，方便 SEO。
- 让后台能直接维护文章、站点页、JSON 资源、资源仓库和 Git 状态。
- 让布局、语言和资源浏览符合实际维护场景，而不是演示页式的堆叠卡片。

## 已落地能力

- 文章列表、详情、专题、分类、标签、工具、文档、搜索、RSS、Sitemap。
- 后台文章编辑、站点页编辑、站点设置、资源仓库浏览、版本控制查看。
- Git 文件预览，支持文本和图片。
- 后台默认中文，登录使用账号密码验证。

## 后续扩展方向

- 文章编辑增强 Markdown 预览和目录。
- 资源仓库补充更完整的目录树与批量操作。
- 版本控制补充差异对比和更清晰的提交历史浏览。
- 公开站点继续补齐页面体验和 SEO 结构化标签。
