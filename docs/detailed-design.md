# 详细设计

本文档记录当前实现的关键设计，便于后续手工修改和代码回看。

## 1. 内容读取

- 内容仓库由 Markdown 文件与同名 `.yml` 元数据组成；两者都存在时以元数据为准。
- 仅在缺少独立元数据文件时才解析行内 Front Matter。
- 文件读取保持同步，避免大量文章连续异步读取造成的长任务链问题。

## 2. Markdown 渲染

- 使用 Markdig（Advanced Extensions + GitHub 风格自动标识符 + 自动链接）。
- 正文中的相对图片地址统一重写为资源域名下的绝对地址。

## 3. 缓存与失效

- 站点、文章、分类、专题等读取结果放入内存缓存，键中包含语言。
- 内容变化通过版本号自增失效，不需要重启进程。

## 4. 代码约定

- 默认中文界面。
- 面向维护者的说明文字尽量短。
- 只有结构复杂的区域才加中文注释。
- 文件组织遵循 `src/` 与 `docs/` 分层，不把源码和文档混在根目录。
